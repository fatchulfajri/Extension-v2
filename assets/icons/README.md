# Icons README

Icon files diperlukan untuk ekstensi Chrome.

## Required Icons

Buat icon dengan ukuran berikut dan simpan di folder ini:

- `icon16.png` - 16x16 pixel (untuk toolbar browser)
- `icon48.png` - 48x48 pixel (untuk extension management page)
- `icon128.png` - 128x128 pixel (untuk Chrome Web Store)

## Design Suggestion

Gunakan design dengan:
- Warna utama: Gradient ungu (#667eea → #764ba2)
- Icon: Dokumen/medis dengan simbol AI atau checkmark
- Background: Transparan atau putih
